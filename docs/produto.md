# Produto

O Gestor é um aplicativo de finanças pessoais para quem quer enxergar o mês com clareza, sem entregar a vida financeira a um banco, fintech ou planilha solta.

## Promessa

Organizar o que entra, cuidar do que sai e planejar o que vem — no próprio celular ou computador, em português, com os dados guardados no dispositivo.

Não há mensalidade, anúncio nem conta na nuvem. O valor está na privacidade e no controle.

## Para quem é

- Quem prefere um espaço próprio, sem sincronizar com serviços externos
- Quem precisa acompanhar o mês: salário, contas, parcelas e metas
- Quem quer instalar no celular como aplicativo, inclusive para uso sem internet depois do primeiro acesso

## O que o produto entrega

| Área | O que a pessoa resolve |
| --- | --- |
| Visão geral | Resultado do mês, receitas, despesas e próximas contas |
| Movimentações | Histórico pesquisável, filtros e exportação CSV |
| Contas previstas | O que ainda vai ser pago ou recebido, com baixa no momento certo |
| Planejamento | Limite de gastos, meta de receitas e objetivos de reserva |
| Relatórios | Destino do dinheiro por categoria e leitura do período |
| Simulador | Quitação de dívida com juros sobre o saldo e projeção de receitas |
| Dados | Backup SQLite, restauração, categorias e lixeira |

## Como se diferencia

- **Local primeiro.** O banco SQLite fica no navegador ou no aplicativo instalado. Não existe servidor de dados do usuário.
- **Um mês de cada vez.** A interface parte do período corrente, com contas no radar e parcelas no mês certo.
- **Celular de verdade.** PWA no Android e no iPhone, além de projeto Android para APK.
- **Português nativo.** Copy, moeda e regras pensadas para o uso no Brasil.

## O que não é

Não é open banking, não sincroniza entre aparelhos e não substitui um banco. Cada dispositivo tem o próprio perfil. Backup é responsabilidade de quem usa.

## Como experimentar

1. Abra a [versão publicada](https://gestor-opal.vercel.app)
2. Use **Conhecer com dados de exemplo** — a demonstração não grava por cima dos dados reais
3. Crie o perfil no aparelho em que pretende usar de verdade
