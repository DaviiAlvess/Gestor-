# Instalar no celular

Os dados ficam no aparelho onde o perfil é criado. Instalar no celular não copia automaticamente os registros do computador.

## Android — Chrome

1. Abra o endereço HTTPS do Gestor no Chrome
2. Toque em **Instalar aplicativo**
3. Abra o ícone na tela inicial, ainda com internet
4. Aguarde **Pronto para usar sem internet**
5. Crie o perfil neste aparelho

## Android — APK

Se as Actions do GitHub estiverem ativas:

1. Abra [Actions → Android APK](https://github.com/DaviiAlvess/Gestor-/actions/workflows/android.yml)
2. Baixe o artefato `gestor-android`
3. Instale o `.apk` no celular e permita a origem, se o Android pedir

O APK de desenvolvimento serve para uso pessoal. Não é a publicação na Play Store.

## iPhone

1. Abra o endereço HTTPS no Safari
2. **Compartilhar → Adicionar à Tela de Início**
3. Ative **Abrir como App da Web**, se a opção aparecer
4. Abra o ícone com internet e aguarde o uso offline
5. Crie o perfil no aplicativo instalado

Não é um pacote para a App Store. O iPhone pode remover arquivos locais se o aplicativo for apagado ou se faltar espaço.

## Atualizações

No aplicativo web, abra com internet. Se aparecer atualização pronta, feche todas as janelas e abra de novo. Isso não apaga o banco. No APK, faça backup antes de substituir a versão.
